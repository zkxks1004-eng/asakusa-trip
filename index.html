  1. 구매: Airalo·Ubigi 같은 글로벌 앱, 또는 국내 여행 eSIM 판매처에서 "일본 3일 데이터" 상품. 하루 1GB면 지도·번역·사진 업로드까지 충분하고, 무제한 상품은 속도 제한 조건을 확인.
  2. 설치(한국에서): 설정 → 연결 → SIM 관리자 → eSIM 추가 → QR 스캔. 설치만 하고 회선은 꺼 둔 상태로 출국. 설치는 인터넷이 필요하니 반드시 출국 전에.
  3. 착륙 후: SIM 관리자에서 eSIM 회선 켜기 → 모바일 데이터를 eSIM으로 지정 → 데이터 로밍 ON. 기존 유심은 통화·문자만 남기고 데이터는 끄기(요금 폭탄 방지).
  4. 안 잡힐 때: 비행기 모드 켰다 끄기 → 네트워크 수동 선택에서 상품에 적힌 통신사(KDDI/SoftBank/docomo) 선택. 나리타 공항 무료 와이파이로 판매처 채팅 문의 가능.
